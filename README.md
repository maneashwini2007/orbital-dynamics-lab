# Orbital Dynamics Lab
[🚀 Launch Interactive Simulation](https://maneashwini2007.github.io/orbital-dynamics-lab/)
A self-contained interactive Newtonian two-body simulator.

## Run
Open `index.html` in a modern desktop or mobile browser. No build step or external libraries are required.

## Included
- Mutual two-body gravity in barycentric initial conditions
- Velocity Verlet and RK4 integrators
- Live orbital energy, eccentricity, semi-major axis and period estimates
- Circular, elliptical, parabolic-threshold and hyperbolic presets
- Sun–Earth, Earth–Moon, binary and equal-mass presets
- Trails, barycenter, vector overlay, grid and live history plots
- Editable masses, separation, speed, G, timestep and simulation speed

## Scientific scope
This is an idealized planar Newtonian point-mass model. It does not include perturbations, relativity, non-spherical gravity, atmospheric drag, collisions with finite-radius bodies, or real-time ephemeris data. The displayed preset initial conditions are illustrative approximations, not precision mission data.
